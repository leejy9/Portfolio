## 0. 프로젝트 한 줄 요약
사용자(이재연)는 채용시장에 "적응형으로 지원서를 넣는" 상태에서 벗어나, **AI 시대에 스스로 욕심낼 만한 커리어 방향(북두칠성)을 과학적·구조적으로 정하고, 그 기준으로 회사/직무를 냉정히 평가해, 빠르게 판단할 수 있는 행동 규칙을 만드는 것**을 목표로 이 대화를 시작함.

## 1. 진행 순서 (실제 대화 흐름)
1. **채용공고 sitting(둘러보기)**: 우선순위 없이 서비스기획/마케팅기획/브랜드기획/교육기획 4개 직무로 사람인(Saramin MCP) 검색 → 신입 가능 공고 리스트업. 목적은 "내가 실제로 다닐 수 있는 회사의 조건"을 감 잡는 것.
2. **AI 시대 희망 역량 5가지 제시** (사용자 원문 그대로 보존):
   - ① 강자독식형 산업에서 견고한 포지션 확보 (대기업의 의무적 변화 vs 스타트업 기회)
   - ② 안 되면 시장 자체를 혁신하는 새 판(스타트업 합류 또는 창업)에 뛰어들기
   - ③ 희망직무1: 반복업무를 직접 자동화하고, 데이터/업무흐름 이해로 그 이상의 가치 창출
   - ④ 희망직무2: 소비자 행동의 "왜"를 읽어 상품/서비스에 반영 (서비스기획 지향의 근거)
   - ⑤ 희망직무3: 개인의 동기/목표설정 어려움을 깊게 이해하고 돕는 포지션 (강의·멘토링·HRD 지향의 근거)
3. **Claude의 1차 fit 분석**: 위 5가지를 채용담당자 관점(fit 중심)으로 재구조화.
   - 1번 vs 2번은 안정성-리스크 축에서 사실상 반대 전략 → 지원서에 동시에 녹이면 "뭘 원하는지 모르겠다"는 신호가 됨.
   - 희망직무 1(자동화)이 evidence 가장 강함(둥지 CRM, CordiaEC, n8n — 단 n8n은 이후 사용자가 "성과·배움 없이 중도포기"로 자평, 메모리에서 직접 삭제함).
   - 희망직무 2(서비스기획/소비자 인사이트)는 리서치 방법론 경험은 있으나 "행동 통찰→실제 상품/서비스 반영" 사례가 아직 구체적으로 확인 안 됨 (미해결 질문으로 남음).
   - 희망직무 3(HRD)은 "1:1 깊은 이해"라는 강점과 실제 지원 직무인 "교육기획(콘텐츠 설계·운영)"의 결 차이가 존재 (미해결 질문으로 남음).
4. **사용자의 진짜 목적 재정의 (이 대화의 핵심 전환점)**:
   특정 경험을 깊게 파는 것보다 먼저, 다음 3단계 틀 자체를 세우고 싶다고 명확화함:
   - **1단계 "북두칠성" 설정**: 자기이해 + 세상이해의 교집합에서 직업 선택 기준을 도출. 배경 동기 = "그동안 상황에 적응하며 나쁘지 않은 선택지를 고르는 '가난 마인드'로 살아왔음. 이제 주도적으로 욕심내고 방향을 정하는 사람으로 전환하고 싶음. 여자친구와의 미래, 시스템에 흔들리지 않는 저항력이 동기."
   - **2단계 "냉정한 구조 분석"**: 북두칠성 기준으로 후보 직무/기업을 놓고 연봉·지역·동료·N년 내 현금축적액·커리어패스 성장·장기 자아실현 부합 여부·"얻는 것 vs 잃는 것"을 파워J식으로 구조화해서 분석.
   - **3단계 "행동 기준화"**: 위 결과를 판단 알고리즘(decision rule)으로 만들어, 새 공고/기업을 볼 때 빠르게 O/X 판단하고 집중 영역을 좁히는 데 사용.
5. **방법론 리서치 실행**: 위 3단계를 "구체적·과학적·논리적으로" 뒷받침할 기존 방법론을 Advanced Research로 조사 → knowledge.md에 원본 보존, 사용자에게 쉬운 브리핑 제공 완료.
6. **프로젝트 영속화 시도(현재 단계)**: 이 대화의 산출물을 GitHub에 파일로 올리고 다른 에이전트와 연동하고 싶다는 요청 → Claude는 GitHub 쓰기 권한/커넥터가 없어 직접 업로드는 불가, 대신 4개 파일(knowledge.md, goal.md, directory.md, lessons.md)을 로컬에 생성해 제공하는 방식으로 대응 중.
7. **저장소 업로드 완료**: 위 5개 파일(README.md, goal.md, directory.md, lessons.md, knowledge.md)을 `leejy9/Portfolio` 저장소의 `career-project/` 디렉터리에 업로드함(브랜치: `claude/markdown-file-upload-w7ecvl`). 이제 새 세션/에이전트는 이 저장소 링크만 있으면 5개 파일에 접근 가능.
8. **Stage 0 착수 — Workview/Lifeview 초안 완성 (2026-09-01)**: 사용자가 직접 작성한 Workview/Lifeview 원문을 정리해 `career-project/workview-lifeview.md`에 저장.
