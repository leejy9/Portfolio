## A. 프로젝트 구조 관련 용어

| 용어 | 정의 |
|---|---|
| **북두칠성** | 커리어 전반의 방향성/기준. "자기이해 ∩ 세상이해"의 교집합에서 도출되는, 직업 선택의 최상위 판단 기준. 목표(goal)가 아니라 판단 기준(criteria)에 가까움. |
| **냉정한 구조 분석** | 북두칠성이 정해진 후, 후보 직무/기업을 감정이 아닌 수치·구조(가중치 매트릭스, 재무 시뮬레이션 등)로 비교 평가하는 2단계 작업. |
| **행동 기준 (decision rule)** | 냉정한 구조 분석 결과를 규칙화해, 새로운 채용공고/기업을 볼 때 빠르게 O/X 판단하고 에너지를 어디에 집중할지 정하는 3단계 산출물. Annie Duke의 kill criteria/tripwire 개념과 동일 계열. |
| **가난 마인드** | 사용자가 스스로 이름 붙인 개념. "상황에 적응해서 나쁘지 않은 선택지를 고르는" 수동적 태도. 굶지만 않으면 다행이라는 식의 방어적 태도. 사용자가 벗어나고자 하는 상태. |
| **sitting 단계** | 구직 탐색 초기 국면. 직무/지역 우선순위를 정하지 않고 최대한 넓게 채용공고를 훑어보며 "내가 실제로 다닐 수 있는 회사의 조건"을 감 잡는 단계. |

## B. 희망 직무 관련 용어 (사용자가 번호로 지칭하므로 이 매핑이 특히 중요)

| 용어 | 정의 | 관련 evidence(경력) |
|---|---|---|
| **1번 (강자독식형 산업 포지션)** | 이미 검증된 시장에서 강자가 더 강해지는 흐름에 올라타는 전략. 대기업의 의무적 AI 전환 vs 스타트업 기회 구도. | 미정 |
| **2번 (새 판/개척 전략)** | 시장 자체를 새로 짜는 프론티어 팀에 합류하거나 직접 창업. 1번과 리스크-안정 축에서 반대 방향. | 미정 |
| **희망직무 1 (자동화/워크플로우형)** | 반복업무에 직접 뛰어들어 자동화하고, 데이터·업무흐름 이해를 기반으로 그 이상의 가치를 창출하는 역할. 채용시장 용어로는 Biz Ops, AX 담당, 프로세스 기획, 그로스 오퍼레이션 등에 해당. | 둥지 CRM 자동화(데이터관리시간 90%↓, 원클릭 리포트), CordiaEC 비즈니스 컨덕터 역할. **n8n 개인 프로젝트는 evidence에서 제외됨(아래 C 참고)**. |
| **희망직무 2 (소비자 인사이트→서비스기획)** | 겉으로 보이는 특성 이상으로 소비자 행동의 근본 동기("왜")를 파악해 상품/서비스에 반영하는 일. 서비스기획 지향의 근거. | 심층/그룹인터뷰 리서치 경험, 국책연구과제 3건. "리서치→실제 설계 반영" 사례는 미확인. |
| **희망직무 3 (개인 동기·목표 조력형/HRD)** | 사람들이 겪는 동기부여·목표설정의 어려움을 깊이 이해하고 필요한 도움을 주는 포지션. 강사·멘토링·HRD·교육기획 지향의 근거. | 강의, 멘토링 4건, 넥스트러너스 부트캠프 운영(이탈률 0%). 단 실제 지원 대상인 "기업 교육기획" 직무(콘텐츠 설계·운영 중심)와는 결이 다를 수 있음(미해결 이슈). |

## D. 방법론 관련 핵심 용어 (knowledge.md 요약 인덱스 역할)

| 용어 | 한 줄 정의 | 이 프로젝트에서의 용도 |
|---|---|---|
| **Workview / Lifeview** | Designing Your Life의 도구. "일이란 무엇인가/삶이란 무엇인가"를 각 250단어로 서술 | 1단계(북두칠성) 자기이해 축 |
| **Good Time Journal** | 매일 에너지·몰입 수준을 실시간 기록하는 저널 | 회고 왜곡(peak-end rule 등) 보정용, 1단계 자기이해 축 |
| **Career Anchors (Schein)** | 8개 커리어 앵커 중 "포기 못하는 자기개념"을 진단하는 40문항 도구 | 1단계 자기이해 축 |
| **80,000 Hours 5요인 프레임** | career capital / personal fit / immediate impact / job satisfaction / exploration value | 2단계 구조 분석의 대분류 기준 |
| **가중 의사결정 매트릭스 (MCDA)** | 후보×기준을 가중치로 점수화해 비교하는 기법 | 2단계 핵심 도구, 사용자의 7개 평가항목을 여기에 매핑 |
| **Pre-mortem** | 결정 전 "실패했다고 가정하고 원인 역추적" | 2단계 낙관편향 보정 |
| **Kill criteria / tripwire** | 사전에 "이 신호가 오면 그만둔다"를 정해두는 것 (Annie Duke) | 3단계 행동 기준의 직접적 근거 |
| **Decision Journal** | 결정 시점의 가정·기대값을 기록하고 결과와 무관하게 과정을 리뷰 | 3단계 실행 습관 |
| **MBTI** | 사용 금지 도구. 신뢰도·예측타당도 근거 약함 | 이 프로젝트에서 채택하지 않음 (Big Five/RIASEC로 대체) |
| **Ikigai 벤다이어그램** | 대중적으로 알려진 4원 다이어그램은 일본 원전과 무관한 서구 창작물 | 성찰 도구로는 사용 가능하나 "검증된 이론"으로 인용 금지 |
